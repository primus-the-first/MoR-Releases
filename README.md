# Ministry of Romance

A playful, private "Official Relationship Application & Contract" for Android.

**Install:** download [MinistryOfRomance.apk](../../releases/latest/download/MinistryOfRomance.apk), open it, and allow installs from your browser or files app when Android asks.

- Everything you enter stays on your phone. Nothing is uploaded or tracked.
- The latest version is always at the link above. Older versions are under Releases.

This repo only holds the built app. It is updated automatically.
